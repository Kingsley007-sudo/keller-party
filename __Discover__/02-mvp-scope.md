# MVP Scope

## Muss in Version 1
- Landingpage mit Couvert-Animation
- Sichtbare Einladungskarte mit Event-Text
- `Request access` Button
- Registrierungsformular
- Erfolgsmeldung nach Versand
- Speicherung aller Anmeldungen
- Admin-Seite mit Liste aller Eintraege
- Aktion pro Eintrag: `Accept` / `Reject`
- Statusspeicherung pro Anmeldung

## Sollte in Version 1.1
- Admin-Login
- Such- und Filterfunktion im Admin-Bereich
- Zeitstempel fuer jede Anmeldung
- Sichtbarer Status: `Pending`, `Accepted`, `Rejected`
- WhatsApp-Link als manuelle Zwischenloesung

## Kann in Version 2
- Automatischer WhatsApp-Versand
- Registrierung mit Gaesten
- Begrenzung der zulaessigen Anzahl an Gaesten
- Duplicate Check
- Export als CSV
- Blacklist
- Check-in fuer Eventnacht
- Invite-Code oder personalisierte Links

## Empfehlung
Fuer schnellen Start sollte das Projekt zuerst als stabiles MVP ohne volle WhatsApp-Automation geplant werden. Das reduziert Risiko bei Meta Business, Template-Freigaben und Messaging-Regeln.
